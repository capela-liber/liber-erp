# Suporte

Não há plano de suporte pago, SLA nem canal comercial. O que existe é este repositório e
gente disposta a responder. Para que a resposta chegue rápido — e sirva a quem vier
depois — cada tipo de assunto tem um lugar.

## Dúvida: use as Discussions

**[Perguntar no fórum →](https://github.com/capela-liber/liber-erp/discussions/categories/q-a)**

Vá para lá quando a pergunta for do tipo:

- como instalo, atualizo ou configuro um módulo;
- como funciona a consignação, o acerto, a retenção de IRRF, o envio à Metabooks;
- por que o campo X mostra esse valor;
- isto que eu quero fazer é possível com o Liber?

A categoria **Q&A** aceita marcar uma resposta como *a* resposta. Faça isso quando sua
dúvida for resolvida: é o que transforma uma conversa em documentação pesquisável.

Antes de abrir, vale uma busca nas discussões já existentes e uma olhada no `NOTES.md`
da pasta do módulo — é lá que estão as ressalvas sobre o que ainda não está pronto.

## Erro ou pedido de recurso: abra uma issue

**[Relatar um erro →](https://github.com/capela-liber/liber-erp/issues)**

Issue é para o que vira trabalho no código: comportamento errado, traceback, campo que
não calcula, recurso que falta. Ajuda muito incluir:

- versão do Odoo e do módulo (ou o commit);
- o que você fez, o que esperava, o que aconteceu;
- o traceback completo, se houver.

Se você não tem certeza se é erro ou se é uso indevido, abra uma discussão — a gente
converte em issue se for o caso. É mais fácil promover uma dúvida a erro do que
arqueologia numa issue que era dúvida.

## Ideia para o roteiro

**[Ideias →](https://github.com/capela-liber/liber-erp/discussions/categories/ideas)**

Para propor rumo, discutir desenho ou dizer o que falta antes que exista código.

## Um aviso honesto sobre prazo

Isto é software publicado na esperança de ser útil, mantido por quem também tem uma
editora para tocar. As respostas vêm quando dá — não quando você precisa. Se o seu caso
tem prazo, a licença [AGPL-3.0](LICENSE) permite que você contrate quem quiser para
implantar, adaptar e dar suporte. Essa porta está aberta de propósito.
